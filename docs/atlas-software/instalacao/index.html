GUIA DO COMPRADOR · CORE BASIC

Do download ao primeiro vídeo, sem depender de suporte.

Este guia acompanha a instalação como se fosse o primeiro computador do cliente. Cada etapa informa o que será verificado e o que nunca deve ser solicitado.

O cliente não precisa instalar Python, Node.js ou FFmpeg.
Esses componentes são empacotados e verificados pelo instalador Atlas. Links técnicos aparecem abaixo apenas para desenvolvimento e diagnóstico avançado.

INSTALAÇÃO

Passo a passo

Baixe pelo portal

Não aceite arquivos enviados por mensagem, drive público ou link permanente.

Verifique o editor

Clique com o botão direito, abra Propriedades → Assinaturas Digitais e confirme o editor antes de executar.

Execute o instalador

Escolha o idioma, leia os termos, confirme a pasta e conclua. O Core não exige privilégios administrativos no modo por usuário.

Abra pelo Menu Iniciar

O Atlas escolhe uma porta local aleatória, gera uma sessão temporária e abre a interface no navegador.

Crie seu workspace

Informe nome, país/idioma e fuso horário. Nenhum token é pedido no Core Basic.

Crie e teste

Crie um projeto, importe uma imagem ou vídeo, gere um vídeo vertical e confirme o limite de cinco exportações diárias.

PRIMEIRO PLUGIN

Instagram será conectado de forma guiada.

TikTok não faz parte do primeiro plugin. Ele será vendido e configurado separadamente.

O cliente prepara

  • e-mail de trabalho acessível;
  • conta Instagram profissional;
  • Página do Facebook vinculada;
  • acesso administrativo ao negócio Meta.

O Atlas faz

  • abre o login oficial da Meta;
  • mostra as permissões solicitadas;
  • valida Página e Instagram escolhidos;
  • salva credenciais no Cofre do Windows;
  • mostra somente valores mascarados.
EXEMPLO DA TELA LOCAL

O token real nunca aparece no site público e nunca é salvo em `.env`. Clientes comuns não precisam criar tokens manualmente; o OAuth oficial faz isso.

Segurança por padrão

Core Basic não possui redes sociais, APIs pagas, anúncios ou renovação automática. Cada plugin é assinado, licenciado e ativado separadamente. Qualquer operação com custo exige confirmação explícita.

AUTOSSUPORTE

Problemas comuns

O instalador pediu Python ou FFmpeg.

Interrompa a instalação. O pacote comercial correto deve incluir ambos. Não baixe dependências indicadas por sites desconhecidos.

O Windows diz que o editor é desconhecido.

Não prossiga com uma versão comercial. Builds internas de teste são explicitamente marcadas como não assinadas e não podem ser revendidas.

O navegador não abriu.

Abra Atlas Creator novamente pelo Menu Iniciar. O aplicativo cria uma nova sessão local; não reutilize URLs antigas.

Onde coloco tokens?

Core Basic não usa tokens. Após comprar um plugin, a aba Configuração mostrará o login oficial ou o campo específico e salvará a credencial no cofre seguro.
