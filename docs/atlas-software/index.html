Configuração assistida

O cliente conecta cada peça, passo a passo.

O Atlas não entrega um arquivo de configuração confuso. Cada plugin abre somente os campos necessários e testa a conexão antes de salvar.

Crie o espaço

Nome do projeto, idioma, país, fuso horário e pasta onde os arquivos serão armazenados.

Escolha o objetivo

Conteúdo próprio, afiliados, negócio local, agência ou produto digital. Isso personaliza os módulos sugeridos.

Adicione suas IAs

O cliente escolhe o provedor e insere a própria chave em uma tela segura. Cada conexão é validada separadamente.

Escolha as vozes

Voz local básica ou plugin de voz premium. Clonagem exige consentimento documentado.

Conecte plataformas

OAuth oficial para cada rede. O cliente vê permissões, conta conectada e limitações antes de publicar.

Ative comércio e dados

Tags de afiliado, páginas, e-mails operacionais, pixels e tokens aparecem apenas nos plugins comprados.

Perguntas importantes

Sem letras pequenas.

O Atlas Core publica automaticamente?

Não. O Core cria, organiza, revisa e exporta. Conectores de publicação são plugins separados e continuam sujeitos às permissões de cada plataforma.

As IAs e vozes estão incluídas para sempre?

O conector pode ser comprado, mas o consumo cobrado por OpenAI, Fish Audio ou outro provedor é pago pelo cliente diretamente ou por créditos Atlas claramente identificados.

O que significa licença perpétua?

A versão desktop adquirida continua funcionando para os recursos locais daquela licença. Serviços de nuvem, suporte prioritário e APIs externas podem exigir planos separados.

Posso começar básico e melhorar depois?

Sim. O objetivo é exatamente esse: começar com Core, preservar os projetos e ativar plugins conforme a operação amadurece.

O produto já está à venda?

A versão comercial modular está em preparação. A página apresenta a estrutura proposta para acesso antecipado; nenhum pagamento é processado aqui.
